# 变更说明 · place-picker 地点选择弹层改版

> 负责人：B ｜ 2026-11-24 ｜ 提交：`bfb3b82` → `985eaf4` → `45d25f4`（三次迭代，均已推 dev）

## 一、背景与问题（用户 11-24 实测反馈）

| # | 问题 | 截图表现 |
| --- | --- | --- |
| 1 | 一级（分类）/二级（片区）/三级（地标）视觉区分度弱 | 三层胶囊同尺寸同配色，层级不清 |
| 2 | 一级菜单显示不完整 | 分类横滑 scroll-view 一行放不下 7 项，右侧被截断且无滚动提示 |
| 3 | 出现不属于当前层级的选项 | 切到「图书馆」后仍显示「南区教学区·全区」和第 30~49 教学楼（上一分类残留） |
| 4 | 面板高度变化生硬 | 有/无地标的片区之间切换时，地标区瞬间插拔 |
| 5 | 切分类无点击反馈 | 胶囊按下无任何视觉响应 |
| 6 | 过渡偏快偏硬 | 级联入场 300ms、展开 320ms，「像直接重置」 |

## 二、实施流程

需求提出后**先出交互式预览图**（HTML mockup，真实配色 + 可点按体验级联动画），用户确认方向并提出调整（**级联只动下一级，已出的层级不重放**）后按调整实施。

## 三、改动明细

### 1. 层级视觉区分（`index.wxss`）

- 一级分类胶囊：56rpx/24 字号 → **64rpx 高 / 28 字号**，选中态由浅棕底改为**深棕实底白字**（`--color-primary-dark`）
- 二级片区胶囊：60rpx → **52rpx 高**（字号 24），比一级小一号
- 一级与二级之间加 **1rpx 全宽分割线**（`#E3D5BF`，比分隔色 `#F1EAE0` 深半档）

### 2. 一级换行平铺（`index.wxml` + `index.wxss`）

- 分类容器由横滑 `scroll-view` 改为 **`flex-wrap: wrap` 换行平铺**，7 个分类全部可见（第二行放「校外/其他」），胶囊补 `margin-bottom` 撑行距

### 3. 切分类重置下级（`index.js`，修层级串味 bug）

- 原 `onCatTap` 只更新 `cat/zoneList`，zone/places 残留上一分类选中态（问题 3 根因）
- 现切分类自动落到**该分类首个片区**：`applyZone(zoneList[0], '')` 统一重算 places/预览/`canConfirm`，下级状态零残留
- 通用口径：**切换上级选项必须重置所有下级状态，不能只改本级**

### 4. 面板高度过渡（`index.wxml` + `index.wxss`）

- 「具体地标」区与「该片区无细分地标」提示条由 `wx:if` 插拔改为**常驻容器 + `max-height 0→1000rpx` / `opacity` 过渡**（480ms/360ms，`--ease-out`）
- 效果：教学区 ↔ 宿舍园等需要面板变长的切换全程平滑，确定栏随动

### 5. 级联入场动画（`index.js` + `index.wxml` + `index.wxss`）

- 口径：**点一级只有二级入场，点二级只有三级入场，已出的层级不重放**
- 实现：`zTick/pTick` 计数器奇偶交替切换动画名（`pp-anim-0` / `pp-in-a` 与 `pp-anim-1` / `pp-in-b`，两组内容相同的 keyframes）触发重放；`animation-delay = index × 40ms` 逐个上浮
- 搜索直选（跨分类跳转）→ `zTick`/`pTick` 同时自增，片区与地标各入场一次
- 参数：入场 **420ms**、递增 **40ms**（用户反馈 300ms 偏硬后放慢）
- 安全性：这些胶囊的按压反馈均为底色变化（无 transform），与 F-11「入场动画 × scale 按压冲突」口径不冲突
- 实现备注：`wx:key` 是特殊属性不吃 `{{}}` 表达式，重放动画用「交替动画名」而非改 key

### 6. 按压反馈补齐（`index.wxml` + `index.wxss`）

- 一级分类、二级片区、三级地标胶囊全部补 `hover-class`：底色变 `--color-surface-2`，150ms 过渡
- 口径与 F-11 一致：小文字控件只变底色，不做 scale 缩放
