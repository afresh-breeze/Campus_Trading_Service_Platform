# UI 改动同步（B · 2026-11-25）

> 给 A 的参考文档：今天 B 侧全部 UI 改动的**最终口径**。A 明天改自己页面时可直接套用同一套
> 类名 / 令牌 / 数值，保持两半小程序观感一致。所有改动已推 `dev`（95eb6d3 及之前）。

## 一、文字层级三档口径（最重要，可直接抄）

**原理**：小程序默认字体（现宋体）下 400 与 500 几乎无差，做「主/次/辅」必须
**字号差 + 字重跨档（400→700）+ 明度差**三者同时拉，只加粗不放大 = 用户看不出。

| 档 | 字号 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| 主 | 32~36rpx | **700** | `--color-text`（#2E2119） | 地点/标题/价格等决策信息 |
| 次 | 24~26rpx | 400 | `--color-text-2`（#6B5B4D） | 描述/补充说明 |
| 辅 | 22~24rpx | 400 | `--color-text-3`（#9A8875） | 时间/编号/label |

已落地的三处样板：
- **大厅订单卡**（`pages/errand/hall.wxml/.wxss`）：取件 `.order__place--from` 36rpx/700；
  送达 `.order__place--to` 26rpx/400 text-2；报酬 `.order__price` 40rpx/700（**无「报酬」二字**，
  ¥ 已含语义）；规格/时间双 `tag tag-gray`（原 tag-warning 橙色会抢焦点，已压灰）；
  描述 `.order__desc` 26rpx + 左侧 2rpx 引线（`border-left: 2rpx solid var(--color-border)`）。
- **详情物品信息卡**（`pages/errand/detail.wxml/.wxss`）：规格 `.detail-info__size-chip`
  胶囊 32rpx/700（`--color-primary-dark` on `--color-primary-light`）；描述
  `.detail-info__desc` 32rpx/**700** 整块左对齐（长文本右对齐单行是可读性 bug）；
  编号/时间收进 `.detail-info__meta`（24rpx 灰阶 + `border-top` 分割线）。
- **详情路线卡**：地点值 `.detail-route__value` 32rpx/700，片区小字
  `.detail-route__value-sub` 24rpx text-3。

## 二、地点文案口径（A 的二手页如涉及地址可复用）

- **列表卡片 / 摘要用短文案**：`campus.shortPlace(area, place)` —— 有具体地标只出地标
  （如「第30教学楼」），无地标退片区名。前提：52 地标全校无重名（smoke_hall [13] 有断言）。
- **详情页 / 筛选 chip 用全量**：`campus.displayArea(area, place)`（「片区 · 地标」）。
- **详情页禁截断**：列表卡可以 ellipsis，详情页地点必须完整显示（用户明确定稿的大忌）；
  自由文本用 `word-break: break-all` 换行，不要 ellipsis。

## 三、按压与入场动画口径

- **按压（hover-class）**：整卡 = `scale(0.985) + opacity 0.94 + shadow-card-hover`
  （见 `.order--hover`）；行/小控件只用 opacity 或底色；**小文字控件禁止 scale**（字抖动根因）。
- **入场动画**：`.u-enter`（app.wxss 全局，上浮 16rpx + 淡入）挂在**动画壳节点**上，
  前 6 张 + `style="animation-delay: {{index * 40}}ms"` 交错；切筛选/排序走列表清空重建，
  节点新建自动重放，无需 js 计数器。样板：`hall.wxml` 的 `.order-anim` 包壳。
- **铁律修正**：u-enter（fill-mode both 长期占用 transform）**不能与 scale 按压同节点**——
  分两层（壳动画 / 卡按压）互不干扰。之前「摘除 u-enter」的准确表述是「摘离按压节点」。

## 四、登机牌式路线卡（详情页，可整体复用）

结构：横向三段 flex（左取件 / 中图标 / 右送达右对齐）+ 虚线下备注行。
- 中段 `.detail-route__mid`：`position: relative`（**必须**，absolute 小人的锚点）+
  `align-self: stretch` + flex 居中（随左右列高度自适应垂直居中）。
- 粒子环 `.detail-route__ring`：84×84rpx，16 个点由 js 预生成（`detail.js` 的 `routeDots`，
  sin/cos 定位 + 距顶角分四档）；四档色全用令牌：`--0 primary-dark`（顶）→ `--1 accent` →
  `--2 text-4` → `--3 border`（底），顶部最深向两侧渐浅。
- 跑步小人：`assets/icons/runner.png`（PIL 生成的 #79513D 圆头笔画剪影，128px 透明底），
  44×44rpx 绝对定位居中。
- 备注 `.detail-route__foot`：3rpx dashed `--color-border` 虚线下，「备注」小灰标签 + 内容。

## 五、全站字体（11-25 定稿：全宋体）

- `app.wxss` `page` 级：`font-family: 'Songti SC','STSong','Noto Serif CJK SC','FangSong','SimSun',serif`
  ——**一处生效全局继承，不要在页面里另设 font-family**（全站仅此一处声明）。
- **44rpx 页面大标题**：宋体 700 视觉偏细 → 统一 `font-weight: 900 + -webkit-text-stroke: 0.6rpx currentColor`
  （app.wxss 已含 `.home-bar__title,.hall-bar__title` 规则，覆盖 A 的二手页标题）。
  真机若描边发糊降 0.4rpx（两处同值：app.wxss + hall.wxss）。
- 已知边界：Android 无宋体机型静默回退黑体；SimSun/宋体 SC 有版权不可内嵌，
  全端一致需换开源思源宋体（OFL）子集 + `wx.loadFontFace`（约 1-2MB）。

## 七、宋体对比度修正（11-25 晚补充，A 页面同步受益）

全站切宋体后，次/辅级文字（text-2/text-3）衬线笔画细，**同色值视觉对比度变浅**
（用户在二手页分类 chip、商品副信息与代取卡送达/胶囊/描述上均有反馈）。已在令牌层修正：

| 令牌 | 旧值 | 新值 | 白底对比度 |
|---|---|---|---|
| `--color-text-2` | #6B5B4D | **#594A3B** | 5.5:1 → 7.4:1 |
| `--color-text-3` | #9A8875 | **#7E6C5A** | 3.5:1 → 4.9:1 |

A 页面所有用这两档令牌的文字（分类 chip、商品副信息、时间等）**自动加深，无需改 A 的文件**。
`--color-text-4`（#C7B9A8，占位/粒子装饰用）保持不变。若 A 觉得加深过度，提出后调令牌一处即可。

## 八、详情页小票化外壳（11-25 深夜补充，B 页专属 + 一个新令牌）

代取详情页四张卡片连成一张「小票」：纸面 + 上下细锯齿边（齿距 26rpx / 齿高 16rpx）+
卡片间虚线撕线；发布者下方为随机线条图案落款 + 当日日期 + 「打印时间」。
**只动外框，四段内容的文字层级一字未改。**A 可复用的点：

> 落款区最初做的是 view 拼条形码，当天即被替换——**太像真码，用户怕引起扫码/支付误会**。
> A 若要做同类装饰，直接用下方图案随机方案，别做条码样式。

| 资产 | 说明 |
|---|---|
| `--color-paper: #FFFDF7`（app.wxss **新增**） | 小票/纸面底色，比 bg-white 略暖；纯增量令牌，不影响任何既有页面 |
| `.receipt` 结构（detail.wxml/.wxss） | 外壳 + 两条齿条（`wx:for` 27 齿纯 CSS border 三角，零图片）+ `.receipt__body .card` 降级覆盖 |
| 落款图案随机方案 | `assets/receipt/` 语义命名素材（`cat/mouse/cake/umbrella/trees.png`，黑线条透明底）+ `onLoad` 里 `Math.random()` 抽一张写 `receiptImage`；**只在开页时定死**（fetch/回跳/下拉刷新不重抽，防闪变）；日期字距 6rpx |

**关键坑（A 复用时必看）**：齿形盒子必须**显式 `box-sizing: border-box`**——
content-box 下 26×32 的盒子会被 16rpx 齿条 `overflow: hidden` 整条裁没（肉眼是一条直线）。
另附一条无真机也能做视觉回归的路子：把 wxss 逐字转 CSS（rpx×0.5）+ 同名 class 的 HTML mock
用本机浏览器无头截图核对，本次齿边几何即由此发现并修复。
