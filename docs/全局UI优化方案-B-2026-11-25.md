# 全局 UI 优化方案（B 侧）｜2026-11-25

> 基于全页扫描（20 页 + 组件 + custom-tab-bar + app.wxss），按「体验 → 一致性 → 体系债」三档排优先级。
> 每条带 file:line 证据，落地时逐条打勾。视差转场丝滑化是本轮最高优先级。

---

## 一、视差转场丝滑化（最高优先级）

### 已定位的三个主因

**主因 1｜入场：setData({parallax:true}) 与 navigateTo 同 tick 发出**
- 证据：`pages/index/index.js:265-266`（hall.js:278、errands.js:245、favorites.js:191、items.js:185、result.js:579 同型）
- 左移动画和原生转场抢启动时序，效果时有时无——「不丝滑」的第一嫌疑。
- **改法**：点击后先让位移走 100ms 再 navigateTo：
  ```js
  this.setData({ parallax: true });
  this._navTimer = setTimeout(() => wx.navigateTo({ url }), 100);
  ```
  六页同型；注意 onUnload 清 timer、连点防抖（导航中再点不重复入栈）。

**主因 2｜返回：onShow 复位与整包 list setData 同帧叠加**
- 证据：`pages/index/index.js:61-66` 复位 parallax 后同一帧 `refresh()` → fetch(1) → 整包 setData list（index.js:173-183）；hall/favorites/items/result 同型。
- 220ms 回弹动画、数据 diff、图片重排三件事挤在同一窗口。
- **改法**：onShow 里复位 parallax 用轻量路径；refresh 延到回弹结束后：
  ```js
  onShow() {
    if (this.data.parallax) this.setData({ parallax: false });
    if (this._needRefresh) this._refreshTimer = setTimeout(() => this.refresh(), 260);
  }
  ```

**主因 3｜作用面积：.parallax-left transform 整页根**
- 证据：`app.wxss:498-503`；根容器含 sticky bar + 全列表 + 每卡双层阴影，返回瞬间整页提升合成层再光栅化，大列表页首帧必掉。
- **改法（三选一，按成本递增）**：
  a) 位移 20px→12rpx、缓动改 `var(--ease-out)`（先做，零风险）；
  b) 视差只移列表区不移 sticky bar（需要 wxml 分层）；
  c) 长列表页（index/hall）干脆不做视差，只保留详情页入场（体验损失最小）。

## 二、按压口径统一（体验级，立即可做）

「按压只压暗不缩放」是既定口径（app.wxss:254-257，scale 导致宋体逐帧重栅格化字抖），但 7 处违规：

- `components/item-card/index.wxss:179-185` `.card--hover scale(0.985)` ← 最伤：点卡片进详情与视差同帧
- `pages/errand/hall.wxss:224`、`pages/mine/errands.wxss:99`、`pages/search/result.wxss:374`、`pages/chat/list.wxss:35`、`pages/chat/detail.wxss:41`、`pages/mine/index.wxss:33`

**统一改 opacity 0.94**（一行一个）。另外补齐漏掉的按压态：
- `pages/mine/errands.wxml:64`、`pages/mine/favorites.wxml:46`、`pages/mine/items.wxml:46`、`pages/chat/list.wxml:36` 重试按钮补 `hover-class="btn--press"`；
- `pages/mine/errands.wxml:131-141` `.me-act` 快捷按钮补按压态。

## 三、令牌收编（一致性级，分批做）

1. **26rpx「幽灵档」**（介于 --font-sm 24 与 --font-base 28 之间）蔓延 20+ 处：index/hall/result/favorites/items 等。**建议新增 `--font-md: 26rpx`** 一次性收编。
2. **item/detail 页字号几乎全裸值**（wxss:80-410 共 21 处 20-52rpx）——令牌化最差的页，整页映射到 --font-*。
3. **mine/index 页** 38/54/30/34rpx 裸值 11 处，同上收编。
4. **font-weight 口径**：正文按钮 500、标题/强调一律 600（现 app.wxss:245 vs :199、tab-bar:85、errands:38 语义混乱）。
5. **硬编码色**：custom-tab-bar/index.wxss:27（`#E6A874`→--color-primary）、mine/index.wxss:13 渐变、`#6A4431` 收编为令牌、chat 两页裸 #ffffff、hall.wxss:183 重复骨架渐变删除、item-card 阴影换 --shadow-card、app.wxss:268 disabled 色令牌化（`--color-disabled-*`）。
6. **间距魔法值**（最严重 6 处）：hall.wxss:212-213、item-card:29/51、index:42/236、mine/index:4/11、errand/detail:459、app.wxss:190 `.card` padding。建议公共层补 `--padding-card: 28rpx`。
7. **radius 补档**：新增 `--radius-xs: 12rpx` 收编 favorites/hall/tab-bar 的 12rpx 散值。

## 四、体系债（收尾级）

1. **z-index 层级表**（全站统一）：sticky 10 / 浮层 20 / fixed 栏 30 / nav-top 40（现与 detail-bar 同 30，改版易互盖，见 nav-top/index.wxss:20 vs item/detail.wxss:298）/ tabBar 100 / **mine/runner.wxss:336 的 1000 归档**。
2. **对比度**：`--color-text-4 #C7B9A8` 白底约 1.9:1（index:249「没有更多了」、favorites:99 划线原价、item-card:168）→ 辅助文字改 --color-text-3；disabled 文字 #9A8875 压 #EBDCC3 约 2:1 → 加深。
3. **错误呈现统一**：「保留列表 + 顶部轻提示条」模式（现在 list-common.js:145 已有列表时只 toast、errands.js:183 有 sections 时完全无提示）。
4. **时间标签语义色对齐**：mine/errands.wxml:119,178 用 tag-warning，hall 同语义已是 tag-gray（hall.wxml:152）——对齐中性灰。

## 五、执行顺序建议

1. **第一批（体验，半天）**：主因 1+2 时序修复 + .card--hover 等七处 scale→opacity + detail 摘类对齐 → 真机验证视差。
2. **第二批（体验，半天）**：视差面积收缩（主因 3a→b/c 视真机效果）+ errand/detail 动画层下沉 + mine/errands 分页。
3. **第三批（一致性）**：--font-md 收编 26rpx + item/detail、mine/index 字号映射。
4. **第四批（体系）**：硬编码色/radius/间距收编 + z-index 表 + 对比度 + 错误呈现统一。

每批跑全量质量门（冒烟 655/0 + 契约 168/0 + wxml_check），涉及 A 页面的改动（item-card 组件、chat 两页）群里同步。
