## 1. 置顶动画：五轮真机迭代（11-26）

**用户反馈序列与对应修正**（`pages/chat/list`）：

1. 「实机演示没有平滑动画，还是生切」→ 两帧 setData + CSS transition 在真机被合并，改 `wx.createAnimation` 两步动画；
2. 「不仅没动画，还频闪抖动，置顶位置错误」→ 换代后倒回旧位方案废弃，改为**先动画后换代**：保持旧顺序、单步滑到目标槽位，340ms 后一次性提交服务端新顺序（`_commitWithReorder`）；
3. 「滑上去直接消失且聊天条乱跑」→ `wx:key="conversationId"` 复用节点残留 transform，改为 `rowKey = conversationId + '_' + seq` 带版本号强制重建节点；
4. 「不要保持左滑形态滑动，先返回聊天条再滑动」→ `onTogglePin` 检测 `swipeX < 0` 先 `_setSwipe(-1, 0, false)`，等 160ms 再 PATCH；
5. 「滑动过程中背景颜色就平滑完成变化，不要结束后生切」→ `showPinned/colorAnimating` 状态类 + 320ms background-color 过渡与位移同帧；另加置顶小箭头常驻渲染 + 320ms 上滑渐显/下滑渐隐（`509796c`）。

**AI 产出**：`list.js/wxml/wxss` 重排动画全链路；专项 `smoke_chat_swipe.js` 24 项（含 stub 补路径展开模拟真实 setData 语义）。

**教训沉淀**：真机动画优先官方 createAnimation；重排先在旧布局滑到位再换代；animation 换代必须换 key 或归零；CSS 过渡需元素先存在；stub 必须模拟真实 setData 语义。

## 2. 聊天条 UI 细节（11-26）

## 4. tabBar 频闪治理两轮（11-26 ~ 11-27）

**第一轮（去频闪）**：录屏取证（opencv 逐帧）确认 `activeIndex:-1` 全灰中间态 + 240ms 延迟跳页是根源，改一次 setData 同帧渲染 + 立即 switchTab（`0958cad`）。

**第二轮（恢复滑动 + 红点防闪断，`d2a3494`）**：用户「没有频闪了，但想保留滑动效果；切到我的页红点先消失再出现」。录屏取证修正了一个错误：此前把开发者工具工具条红色「结束录制」按钮误判为红点；重新按手机画面区域统计，203 帧红点恒在 → 闪断为**亚帧级渲染竞态**。对策：
- 滑动恢复：同帧点亮 → 胶囊滑 260ms（与 wxss 0.26s 对齐）→ switchTab，连点 clearTimeout 打断；
- 红点防闪断：`setBadge` 收到 0 走 400ms 确认窗（`BADGE_CLEAR_CONFIRM_MS`），期间非 0 到达即取消，「1→0→1」竞态被抹平；真正清零仅延迟 400ms 无感知。

**后续（队友）**：真机多次切换出现高亮闪回，队友提交 `63894a9` 改为「广播隐藏实例（离屏渲染落最终态）+ 立即跳页」，滑动延迟被移除；AI 不回退该实现，同步更新 smoke_ui_round2 过时断言（`6ceb32b`）。

**教训**：取证前先看整帧确认分辨率与布局；亚帧闪烁用「延迟确认窗」抹平竞态比追渲染时序更可靠；多人协作期改公共组件后必须同步既有断言。

**二手详情页的三轮返工（最重要的教训）**：
1. 第一轮只改了 `mapDetail` 返回 `galleryPlaceholder`，静态断言通过 → 用户实测仍只有文字；
2. 第二轮把「图片加载失败降级分支」也从纯文字改成插画占位（两条降级路径必须一起改）→ 用户实测仍不显示；
3. **真根因**：`applyDetail()` 的 `setData` 是逐字段拷贝，`galleryPlaceholder` 没进清单 → wxml 的 `src` 一直是空串。补进 setData 后用 mock 数据实跑 `applyDetail` 运行时验证（`images: []`、`galleryPlaceholder: /assets/placeholder/ph-7.png`）才确认生效（`a6d1adf`）。

**教训**：页面若用逐字段 setData，map 函数新增字段必须同步加进 setData 清单；同一语义的多条降级路径（无数据/加载失败）必须一起改；静态断言不够，要用 mock 数据跑一次运行时验证 data 真的到位。

## 7. 聊天页点空白收不起键盘（11-27，`c454032`）

真机反馈：发消息时点空白处键盘收不下去。根因是输入框 `hold-keyboard=true`（连发消息时点「发送」不收键盘）的副作用。修复：保留 hold-keyboard，消息区 scroll-view 加 `bindtap="onTapHideKb"` → 键盘弹出时调 `wx.hideKeyboard()`；发送按钮/选图入口不在消息区内不冒泡，连发节奏不变。

## 8. 代取发布页必填红星（11-27，`bc3b065` / `1a07927`）

对齐二手发布页：取件地点/送达地点/时间要求/报酬四个必填项标签加 `<text class="req">*</text>`（`margin-left: 4rpx + --color-danger`，页面级作用域各自声明）；选填项（规格/描述/图片/备注）不加。用户反馈括号导致红星错位，标签按用户口径改为「报酬/元*」。

## 11. 会话级经验总结

1. **真机优先**：所有动画/交互结论以真机录屏取证为准，先看整帧确认布局再裁剪分析；
2. **数据流三段式检查**：map 函数算出 → setData 写入 → wxml 绑定，缺一段就"看起来改了但没生效"；
3. **降级路径成对改**：无数据与加载失败是同一语义的两条路径；
4. **竞态用确认窗**：亚帧级闪烁（红点闪断）用延迟确认抹平，比追渲染时序可靠；
5. **多人协作**：队友改公共组件后，先读新实现再同步测试断言，不盲目回退。
