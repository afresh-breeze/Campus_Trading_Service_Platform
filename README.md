# 校园易站 · Campus Trading Service Platform

面向西南大学在校学生的校园服务微信小程序，把二手交易、代取跑腿和站内沟通集中到一个入口。项目为《数据库原理与应用》课程设计作品，包含完整的小程序前端、Express REST API 与 MySQL 数据库。

## 功能特性

### 二手交易

- **浏览与搜索**：首页分类浏览，支持关键词、分类、价格与时间排序；书籍商品在搜索结果中以书目卡片聚合，同书商品优先展示。
- **商品详情**：图片轮播、价格与原价、成色、议价标记、卖家信息与信用分；支持收藏、联系卖家和卖家状态管理。
- **发布商品**：普通商品与书籍两种模式；书籍模式支持书目联想与手动新建书目，发布时自动关联书目。
- **状态管理**：在售、已预订、已售、已下架四态流转；预订/下架后自动从首页和搜索隐藏，重新上架无需重发。
- **我的发布与收藏**：按状态筛选、分页加载；我的发布只读，状态操作统一在商品详情页完成。

### 代取跑腿

- **发布代取**：按“片区 + 具体地标”选择取件位置，填写送达地点、规格、报酬与时间要求，可附 0-3 张物品图片；支持直接发布到大厅或先建私单。
- **找跑腿匹配**：供给端可多选服务片区/地标、设置按日期或星期循环的在线计划、可接规格与基础报价；需求端可按区域、规格和时间筛选匹配。
- **接单与履约**：大厅接单、私单联系后接单；发布者撤回、接单者释放、确认完成，订单状态与日志完整留痕。
- **我的代取**：区分“我发布的”和“我接的”，支持状态筛选和分页。

### 站内沟通

- 文字与图片消息、3 秒增量轮询、未读数与已读状态。
- 会话与商品/代取订单绑定，聊天页顶部展示业务卡片，可直接回到详情页。
- 会话列表支持左滑置顶、标为未读和删除；置顶会话始终排在前面。

### 个人中心

个人资料、我的发布、我的收藏、我的代取、接单设置、帮助反馈。

## 技术栈

| 层次 | 技术 |
| --- | --- |
| 客户端 | 微信小程序原生 WXML / WXSS / JavaScript |
| 服务端 | Node.js、Express、`mysql2` 连接池、参数化 SQL |
| 数据库 | MySQL 8.0（InnoDB、`utf8mb4`） |
| 鉴权 | JWT + bcrypt 密码哈希 |
| 定时任务 | `node-cron` 每分钟维护跑腿在线计划 |


## 数据库设计

数据库共 14 张表，按业务分为四条主线：

| 主线 | 表 | 说明 |
| --- | --- | --- |
| 用户与二手 | `users`、`books`、`categories`、`items`、`item_images`、`favorites`、`item_status_logs` | 用户、书目、商品、图片、收藏与状态日志 |
| 代取 | `runner_profiles`、`runner_item_sizes`、`errand_orders`、`errand_status_logs` | 跑腿设置、可接规格、代取订单与状态日志 |
| 聊天 | `conversations`、`messages` | 会话、会话置顶与消息 |
| 反馈 | `feedback` | 用户意见反馈 |

配套 **4 个视图、5 个存储过程、2 个函数、5 个触发器**，用于列表聚合、未读数统计、并发接单、状态日志与冗余字段维护。数据库不使用事件，跑腿自动上下线由 Node 定时任务完成。

详细字段与设计理由见 [数据库 14 张表设计详解](docs/数据库14张表设计详解.md)。

## 接口

后端提供 **43 个 REST 接口**，统一响应格式：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

鉴权使用 `Authorization: Bearer <token>`；接口清单、字段、分页和错误码见 [接口文档 v0.11](docs/接口文档.md)。

## 快速开始

### 环境要求

- Node.js 18+
- MySQL 8.0
- 微信开发者工具

### 1. 初始化数据库

使用 root 执行建库、建表与数据库对象脚本；`cs_app` 业务账号按 [A 成员开发计划与 Git 协作手册](docs/A成员开发计划与Git协作手册.md) 创建并授权：

```powershell
mysql -u root -p -e "source database/schema.sql"
mysql -u root -p -e "source database/objects.sql"
```

也可以直接用最终备份恢复：

```powershell
mysql -u root -p -e "source database/campus_service_dump.sql"
```

> 注意：dump 内含 `DROP TABLE` 和 `USE campus_service`，导入会覆盖同名库；导入前请先备份现有数据库。dump 只含课程演示账号的密码哈希和假手机号，不含真实凭据。

### 2. 启动后端

```powershell
cd server
npm install
Copy-Item .env.example .env   # 已有 .env 则跳过
# 编辑 .env，填写 DB_PASSWORD 与 JWT_SECRET
npm run seed
npm start
```

服务默认监听 `http://127.0.0.1:3000`，健康检查：

```powershell
curl http://127.0.0.1:3000/api/health
```

### 3. 运行小程序

用微信开发者工具导入仓库根目录，确认：

- `miniprogram/config.js` 的 `ENV.dev` 为 `http://127.0.0.1:3000`
- `MOCK` 为 `false`
- 本地开发勾选“不校验合法域名”
